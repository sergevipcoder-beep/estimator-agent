# Сервис аренды спецтехники
Клиент: компания по аренде строительной техники.
Тип проекта: веб-приложение. Итоговая цена: 1 050 000 руб. Срок: 5 месяцев.

Состав работ: каталог техники, календарь занятости по единицам,
онлайн-бронирование с залогом, договоры по шаблону, учёт моточасов,
кабинет для постоянных клиентов с отсрочкой платежа.

Что пошло не так: календарь занятости единиц техники с учётом времени
на перегон между объектами. Логика похожа на расписание врачей из проекта
по стоматологиям, но мы не переиспользовали код и написали заново.
Потеряли около 50 часов.

Вывод: завести внутреннюю библиотеку решений по повторяющимся задачам.
Календарь занятости ресурсов встречается в каждом третьем проекте.
