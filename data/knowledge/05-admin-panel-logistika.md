# Админ-панель для логистической компании
Клиент: транспортная компания, грузоперевозки по РФ.
Тип проекта: админ-панель. Итоговая цена: 420 000 руб. Срок: 2.5 месяца.

Состав работ: CRUD по заявкам, водителям и машинам, статусы доставки, загрузка сканов
накладных, экспорт в Excel, права для диспетчеров и руководителей.

Что оказалось проще ожидаемого: клиент принял стандартную админку на готовых компонентах
без кастомного дизайна. Сэкономили примерно 40 часов вёрстки.

Вывод: для внутренних инструментов кастомный дизайн почти никогда не нужен.
Предлагать готовую дизайн-систему по умолчанию и продавать дизайн отдельно
только если клиент настаивает.
