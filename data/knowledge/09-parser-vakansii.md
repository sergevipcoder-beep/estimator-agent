# Парсер вакансий для кадрового агентства
Клиент: кадровое агентство, работа по IT-вакансиям.
Тип проекта: парсер. Итоговая цена: 210 000 руб. Срок: 1.5 месяца.

Состав работ: сбор вакансий с 3 job-сайтов, дедупликация, фильтры по стеку
и зарплате, выгрузка в Google Sheets, ежедневная сводка на почту.

Что оказалось сложным: дедупликация. Одна вакансия публикуется на трёх сайтах
с разными формулировками. Простое сравнение строк давало 40% ложных дублей.
Решили через нормализацию и сравнение по компании плюс вилке зарплат.

Вывод: задачи на сопоставление похожих записей всегда дороже, чем кажется.
Для таких задач стоит сразу смотреть на векторный поиск вместо строкового сравнения.
